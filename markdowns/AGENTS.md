# Antigravity Rules & Directives

## ⚡ Startup Directive: Superpowers Workflow
- At the start of every conversation or user request, you MUST invoke the `using-superpowers` skill before taking any action or responding.
- If a task involves brainstorming, debugging, planning, or testing, activate the corresponding `superpowers` skill (`brainstorming`, `systematic-debugging`, `writing-plans`, `executing-plans`, `test-driven-development`, etc.).
